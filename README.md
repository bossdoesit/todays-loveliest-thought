# Today’s Loveliest Thought

A responsive, build-free static landing page. HTML, CSS, and vanilla JavaScript. Ready to add to a GitHub repository and connect to static hosting.

## Preview

Open `index.html`, or run `python3 -m http.server 8000` from this folder and visit http://localhost:8000.

## Contents

- `index.html`: public page and accessible journal prompt.
- `styles.css`: responsive brand styling.
- `script.js`: local text-file download and clear controls.
- `assets/`: supplied artwork compressed for web; no banner regeneration.

## What works now

Anchor navigation, mobile layout, reflection entry, text-file download, and clear confirmation. Reflection text is held only in the current page; there is no server submission, browser storage, analytics, email list, payment integration, or account system. Download before leaving if you want a record.

## GitHub and hosting

Create a repository and upload this folder's contents to its root. Commit changes there as the source of truth. For GitHub Pages, publish the main branch root. For Cloudflare Pages, connect the repo as a static HTML project with no build command and the root as the publish directory. Confirm the settings presented by your hosting account before deploying. No npm install or build step is required.

Do not upload the private business plan, campaign kit, internal notes, or credentials into the public deployment directory. They are deliberately excluded from this site package. Review artwork and font rights before public launch.

## Editing

Edit headings/copy in `index.html`. Palette variables are at the top of `styles.css`. Replace images in `assets/` with matching filenames or update their HTML references. The title wordmark is supplied artwork; this package does not include or claim a licensed Angle Estarossa font file.

No repository has been created or pushed, and this package has not been publicly deployed.

## Favicon

The supplied sunflower, butterfly, and crescent artwork is used intact for the multi-size ICO, PNG browser icons, and Apple touch icon. Only resizing/format conversion was applied.

## Animated hero and sharing card

The supplied sunset video is encoded as a silent, fast-start H.264 MP4. It plays once with no loop, keeps the ending frame, and has a pause/play/replay control. Reduced-motion users see the final-frame poster until choosing play. Autoplay refusal leaves an explicit play control. The 16:9 composition is preserved on mobile.

`assets/og-image.jpg` is the 1200 x 630 sharing card. Open Graph and X metadata use the purchased domain. These image URLs become reachable only once the site is hosted and the domain is connected. No public deployment has occurred.
